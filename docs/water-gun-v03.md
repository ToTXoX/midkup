# 简洁卡通水花 v0.3

日期：2026-11-03。

按用户要求保留简洁、可爱的表现。借鉴参考作品的“撞击 → 展开 → 碎散 → 消失”节奏，以四道清楚的水花轮廓、少量大水滴和淡水纹表达落地反馈。

## 本次调整

- 四道水花采用不等大小、不同方向的弧形轮廓，颜色为浅蓝加一小段白色内弧。
- 水花出生时间为撞地后的 0、0.018、0.103、0.127 秒，分成前后两拍。
- 每道约持续 0.21 秒。展开时向外移动、抬起，随后变薄并淡出，不保留站立的水团。
- 飞溅散滴减为四颗，略放大，减少细碎噪声。
- 落点底色是紧贴地面的一小块淡蓝色，随接触结束迅速淡出。
- 水纹缩小、变淡，约 0.48 秒散去；湿斑强度降低。
- 继续保留起喷水珠、弧形水流、断流余水、嘴部挂点、暂停、进度拖动与慢放。
- 取消落地水花的体积场求解，形状初始化后复用。
