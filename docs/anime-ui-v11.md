# 庭院日和 · 动画风界面 v11

界面使用与三渲二场景相配的平涂颜色、深蓝灰轮廓、纸片层次与少量日文装饰。主文字保持中文，操作仍为点草地移动、点按水枪喷水、拖动技能键瞄准。

## 视觉

- 奶油白 `#fffbed` 作为面板底色，浅水蓝 `#72c7dd` 作为选中态，暖金 `#f4c873` 用于技能环与命中徽章，蓝灰 `#3b5b70` 作为清晰描边。
- 标题改为「水跃鱼的庭院」，手机上用「庭院日和」。新增原生 SVG 水跃鱼头像，头鳍、橙色腮鳍和闭嘴笑脸延续角色特征。
- 底部角色卡包含头像、练习标题、纸片对话框、步态按钮和辅助操作。实色底与偏移阴影形成动画道具般的层次。
- 命中次数独立为右上角金边星形徽章；清空次数按钮放在徽章内，减轻角色卡上的操作密度。
- 水枪技能键使用双层描边、金色进度环、平涂水蓝底和小星饰。直径仍为桌面 88 / 手机 82 像素，保留原有触控捕获与松手发射。
- 准星标签使用同样的纸片描边；「命中 +1」加入暖金描字、星饰和短小的「ナイス！」。
- 动作预览面板同步为相同颜色与按钮风格。所有头像、星饰、步态图标均为本地 SVG，不新增图片或字体网络请求。

## 接入范围

界面样式集中在 `animation-test/src/anime-ui.css`；结构与 SVG 位于 `animation-test/resources.html`。`main.js` 负责命中徽章显隐、两位计数和命中时的小幅反馈，并为手机角色卡预留相机空间。游戏模型、材质、水流外形与施法逻辑沿用现有版本。

## 验证

运行技能键触控测试、移动碰撞回归、七动作与场景的可视预览，并完成生产构建。桌面与手机预览：`renders/toon-ui-v11-garden.png`、`renders/toon-ui-v11-garden-mobile.png`；可视检查记录为 `docs/toon-ui-v11-browser-tests.json`。
