# 庭院水枪练习 v0.9

入口：`http://127.0.0.1:5173/resources.html?scene=garden`。

## 操作与节奏

默认点草地移动，点靶子停止移动并锁定。瞄准时身体以每秒最多 8 弧度转向，头部根据低弧线轻轻上抬。按空格或屏幕按钮后先转正，再播放一秒 `WaterShoot`：0–0.23 秒闭嘴准备，0.23–0.33 秒张嘴，0.33–0.66 秒连续出水，0.68–0.90 秒合嘴，最后回到待机。施法期间忽略重复发射和换靶，移动模式、回到起点与切换场景可取消当前施法。Esc 返回移动模式。

准星四角包围目标，不绘制预瞄曲线或移动指示线。暖色标签提示距离太远、被遮挡，淡金色提示可命中。瞄准模式下可点击草地自由喷水；三种练习靶当前均为静止目标。手机靶点有 36 CSS 像素触控区，不依赖悬停或键盘。

## 弹道与判定

弹道使用初速度 9 米/秒、重力 20 米/秒²，与现有可见水枪相同。低弧线解根据实际嘴部位置与目标高度计算，最大水平选择范围 4.4 米；高处目标的有效射程更短。真正开始出水的瞬间读取嘴部与冻结弹道，避免准备阶段头部动作造成水流偏移。

以 20 毫秒片段检测真实庭院和靶子网格，取最早接触。墙面、屋顶、草地和靶子均可拦住水流；只撞到底座或柱子不算靶面命中。被挡住或打空时仍显示真实接触水花，不给分。每次发射有编号，第一股水到达靶盘才加一次，持续水束不会重复加分。水花沿实际接触面法线朝外展开。

从出生点射向普通、滑轨、重型靶时，首个接触约在动作 0.69、0.79、0.72 秒；具体时刻取决于发射时嘴部位置。出水前和飞行途中均不提前计分。

## 命中表现

靶板与立柱绕底座上方短促后仰、回弹，底座保持落地。普通靶与滑轨靶的摆动系数为 0.24，重型靶为 0.10；指数衰减的摆动 0.8 秒后归零。靶心外扩一圈水白色闪光与四颗短光点，0.33 秒消失。命中点同时展开既有的卡通四瓣水花和少量水滴。

「命中 +1」从靶子上方轻轻上浮，在 0.75 秒内淡出；面板累计命中次数并提示目标名称。「清空命中」重置三种靶子的计数和反馈状态。所有反馈几何与材质复用，不随每发创建新贴图或网格。预测碰撞按嘴部位移与低频刷新缓存，避免静止瞄准时持续扫描整个庭院。
