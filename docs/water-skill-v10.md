# 水枪技能键 v0.10

入口：`http://127.0.0.1:5173/resources.html?scene=garden`。

本版将水枪独立为右下角的圆形技能键，电脑与手机共用同一套操作，不需要在移动与瞄准之间切换。

| 操作 | 结果 |
| --- | --- |
| 轻点草地 | 移动并清除旧锁定 |
| 轻点水枪 | 未锁定时朝当前方向喷一发；已锁定时射向靶心 |
| 按住水枪并拖动 | 自由调整方向，显示落点准星；松手发射一发 |
| 轻点靶子 | 可选锁定，不自动喷水 |
| 空格 | 与点按技能键相同 |
| Esc、系统触控取消、窗口失焦 | 取消未发射的拖动 |

技能键桌面直径 88 像素、手机 82 像素，使用浅青色底、水滴符号与「水枪」文字。按下时出现柔和的圆形触控范围，内部图案最多偏移 22 像素，随手指给出方向反馈。拖动超出按钮边缘仍由原指针控制，不会误触相机或地面移动。无需等待长按计时，拖动超过 8 像素即进入方向调整。

自由方向按当前相机的地面朝向计算，落点距角色中心 2.8 米；近远暂不另外调整。松手后由原有逻辑自动转正、闭嘴准备，再实际出水。准备、喷水与恢复期间技能键保持清晰可见并显示阶段文字与环形进度，单次动作结束后恢复可用。已锁定靶子时，拖动技能键会改为自由喷水。

保留三种靶子命中回弹、水花、闪光与「命中 +1」。命中仍以水真正接触靶面为准，原有碰撞、射程和每发一次计分规则保持一致。

输入模块位于 `animation-test/src/water-skill-input.js`，随资源包复制到 `game-assets/gameplay/water-skill-input.js`。手势使用 Pointer Events 和指针捕获；合成 click 不重复发射，键盘 Enter 与空格各发射一次。系统触控取消、丢失捕获、页面隐藏、暂停、重置与场景切换会清理手势。内部 combat mode 保留用于管理状态，界面不显示模式开关。

`npm run test:skill` 在真实 Edge 引擎中运行，包括 CDP 原生 touchStart / touchMove / touchEnd / touchCancel 触控事件。覆盖无目标点按、自由拖动、按钮外释放、取消、可选锁定、暂停、手机技能键布局、触控计分、恢复移动、键盘与场景切换。结果保存在 `docs/water-skill-v10-tests.json`，截图为 `renders/skill-v10-*.png`。
