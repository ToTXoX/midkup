# 庭院移动与碰撞 v0.7

本地入口：<http://127.0.0.1:5173/resources.html?scene=garden>。

## 交互

点击草地后，水跃鱼平滑转向并移动；到达后返回待机。默认小跑，也可切换悠闲走。途中点击新位置会立即重新规划路线。支持暂停、继续、回到起点、重置视角和返回动作台。拖动镜头不触发移动，手机可直接点地面，双指缩放。

庭院使用较小的独立控制面板。镜头根据实际场景顶点和可用屏幕范围自动取景，为桌面侧栏与手机底部控件留出位置。白色细线和绿色圆环提示路线与终点。

## 碰撞与寻路

关卡提供 22 个障碍：房屋、13 段栅栏、7 棵树干与水池。运行时加入三种靶子的圆形占地，并根据网格增加树果篮，共 26 个障碍。草、花朵和低矮灌木继续作为可穿过的装饰。

采用 0.4 米角色圆形占地、0.04 米余量与水池额外 0.12 米岸距。对整个移动线段计算与扩张后障碍的距离，避免较大时间步穿过薄墙、树干或栅栏。尾鳍不单独计算刚体碰撞。

路径优先直达；有障碍时使用约 0.16 米网格的八向 A*，对角边同样进行完整碰撞检查。随后将可直达的路径节点合并。点击障碍内部或无法到达的区域时，终点调整为当前连通区域内接近点击位置的可达地面。抵达或中断时清理路线显示。

地面高度通过 `NAV_Ground` 网格射线取样，角色高度为实际地表 +0.005 米；移动速度沿用动画配置，走路约 0.262 米/秒、小跑约 0.58 米/秒，与步频设置一致。大角度转身阶段减少位移，避免瞬间转向。

## 文件

- `animation-test/src/garden-navigation.js`：二维碰撞、A*、目标修正与路径跟随，不依赖 Three.js。
- `animation-test/src/main.js`：角色转向、动作衔接、操作与庭院取景。
- `animation-test/src/resource-preview.js`：地面取样、点击拾取与树果篮占地。
- `game-assets/levels/garden.json`：占地与寻路设置，构建脚本同步保留设置。
- `game-assets/gameplay/`：可复用模块及接入说明。

## 验证结果

`npm run test:movement` 验证薄墙阻挡、绕行、不可达目标、一次跨越很长距离时的线段碰撞、真实关卡的多种障碍与 100 次中途改点。使用独立的圆形占地检测复查轨迹。

Edge 浏览器测试验证实际鼠标点击后移动、到达待机、绕靶子移动、点击房屋/水池/树干/边界后的终点修正、实际地形高度、暂停与步态切换、镜头拖动、390×844 手机点触与模式切换。结果记录在 `docs/garden-movement-browser-tests.json`，截图位于 `renders/garden-movement-*.png`。

既有的三段动画测试、七段资源测试、水枪测试与三渲二截图检查均通过；浏览器无错误或警告。六个 GLB 格式验证通过。Vite 构建通过，保留已有的 JS 体积分包提示。

本版碰撞针对静态障碍，不包含跳跃、游泳、移动靶子的动态避障或喷水命中逻辑。
