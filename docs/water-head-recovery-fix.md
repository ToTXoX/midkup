# 喷水后头部闪动修正

根因是程序瞄准直接改写 Head 四元数，而 Three.js 的骨骼动画混合器会缓存并跳过未变化值的写回。WaterShoot 收尾约 0.95 秒起头部关键帧恒定，此时程序把抬头偏移重复叠加到上一帧的结果；Idle 恢复写入后突然归位，形成闪动。

现在瞄准层保存动画基础四元数，在每次 mixer.update、动作切换和 seek 前恢复，再计算本帧瞄准姿态。取消瞄准时也恢复基础姿态；重复调用 pose 不再累积偏移。保留既有动作混合时间、施法节奏和弹道规则。

修复前，120 FPS 普通靶收尾出现约 2.23 弧度的单帧跳变；修复后同一收尾区间最大变化约 0.0005 弧度。`npm run test:head-recovery` 覆盖 30 / 60 / 120 FPS、三种靶子、自由喷水、长时间保持瞄准、嘴部位置连续性与暂停。报告位于 `docs/head-recovery-tests.json`。
