# 喷水效果改造 v0.2

日期：2026-11-03。

本次将预览中的浅蓝圆柱与整齐圆球替换为独立的运行时水枪效果。入口仍为 `animation-test/resources.html` 的“喷水”。

## 画面

- 起喷前嘴边鼓起一个小水珠，与口腔略有重叠。
- 水流有细颈、粗细变化和圆润水头，沿轻微下落的弧线推进。
- 0.46 秒停止出水，已喷出的余水继续前进，并断成不等长的三段水团。
- 水滴大小、出生时间、散开方向和速度各不相同，快速时呈梭形。
- 水流与实际地面接触后出现有厚度的中心积水，边缘翻起五处低矮水瓣和小水珠。积水与水瓣使用同一块封闭的三维隐式曲面，相互融合；回落时水瓣收回水心。
- 水冠收拢后留下两圈扩散水纹、薄水膜与边缘不规则的湿斑，逐渐淡去。
- 材质为半透明青蓝水体，边缘较深，表面有短小高光；没有额外光晕或图片依赖。

## 时间与交互

继续使用原七段骨骼动画和嘴部挂点。起喷 0.17 秒、断流 0.46 秒、身体动作 0.7 秒，这些时间从动画元数据读取。

落点时间由飞行路径和场景接触位置计算。角色回到待机后，水纹继续衰减；玩家主动切换到别的动作时清理旧效果。暂停、慢放与反向拖动进度都能控制这段效果。

喷水时预览镜头会拉远，显示完整水流与落点。“喷水播放速度”滑杆支持 0.25×、0.5×、0.75×、1×；其他动作继续使用原本的步频控制。

侧边控制面板占用的宽度计入喷水构图，窄窗口中也能看清落点；手机仍采用上方预览、下方控制的构图。

重复发射前后的 GPU 几何体、纹理和着色器程序数量保持一致。浏览器控制台无错误、警告或失败请求。完整资源预览测试与生产构建另行通过。
