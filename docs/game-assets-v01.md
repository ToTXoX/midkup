# 游戏资源与基础动画 v0.1

日期：2026-11-03。

本轮已完成七段基础动作、静态庭院的 Web 材质转换、道具拆分、资源清单及预览验证。完整使用说明见 `../game-assets/README.md`。

## 角色

在原 24 根蒙皮骨骼上保留公共 MotionRoot，共 25 根导出骨骼。新增 Run、Eat、WaterCharge、WaterShoot，连同已有 Idle、Walk、PetReaction 一起导出到 `characters/mudkip/mudkip.glb`。

没有改变角色拓扑、UV 或原始颜色贴图。四肢使用解析 IK 逐帧生成并烘焙为普通骨骼关键帧，运行时不依赖 Blender 的约束求解。

嘴部 Empty 挂在 Head 上。导出脚本将挂点的轴向归一到 glTF 的 +Z，并在浏览器中验证实际发射方向。动作均无水平根位移，游戏代码控制整个角色容器的位置。

## 庭院与道具

- 来源为已确认的 `mudkip-garden-v11-perspective.blend`，保留小屋、树木比例与摆位。
- 去除隐藏的旧素材方案、角色、预览地板、灯光和镜头。
- 将 365 个可见零件按用途整理为 10 个静态分组。三种靶子和树果单独导出，方便后续摆放、移动与命中判断。
- 草地的小径、沙岸和树脚过渡，以及树木渐变颜色，通过 Cycles 发光通道烘焙到顶点颜色。颜色不包含固定灯光阴影，允许 Three.js 重新布光。
- 场景约 157,071 三角面，10 个语义分组在 Three.js 中因不同材质展开为 50 个渲染网格。
- Meshopt 将庭院从 8,848,060 字节压缩到 2,601,896 字节。未压缩版本留在 `game-assets/source/` 便于兼容与排查。
- `levels/garden.json` 含角色出生点、总览镜头、三种靶子坐标和命中区域、22 个基础障碍范围与场地边界。
- `manifest.json` 含各运行文件路径、字节数、SHA-256、三角面和动画名称。

## 验证

- 所有六个 GLB 均经过 Khronos glTF Validator 检查，0 错误、0 警告。压缩场景还实际通过 Three.js MeshoptDecoder 解码和显示。
- 七段动画在真实 Edge 浏览器中核对时长、蒙皮变形及无水平根位移；循环动作首尾误差小于 0.0001 米。
- Blender 烘焙时四肢目标均可达。浏览器中走路和小跑的抽样接地高度变化分别约 0.081 毫米、0.332 毫米，包含逐帧关键帧之间的插值误差。
- 进食的树果送入口与消失时间、蓄力持续播放、喷水起止时间、单次动作回待机均已核对。
- 动作中断会清理位移目标和对应特效预览，不遗留旧动作。
- 检查桌面与 390 × 844 窄屏的动作台、庭院总览，并保存截图。
- 运行时的浏览器控制台无错误、警告或失败请求。旧版三动作测试也已回归通过。
- 生产构建包含 `index.html` 与 `resources.html` 两个入口。

机器可读记录：`game-animation-validation.json`、`garden-export-report.json`、`game-assets-validation.json`、`game-resources-browser-tests.json`。预览截图位于 `../renders/game-resources-*.png`。
