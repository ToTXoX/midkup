# 庭院果篮互动

点击庭院中的果篮，水跃鱼自动走近，再依次咬住、咀嚼、咽下、满足并回到待机。每次点击触发一颗，连续点击同一次进行中的互动不排队、不重启动作。互动完成后可以再次点击。果篮没有文字标识或悬停提示，闲置时每隔 4 秒闪过一次约 0.8 秒的小亮光；闪光尺寸为 14 像素，峰值不透明度为 1。进食互动期间隐藏亮光，暂停时冻结，系统偏好减少动态效果时关闭。

果篮的真实网格边界用于计算占地；在周围 32 个候选位置中选择可到达且路线最短的站位。站位预留果篮半径、角色碰撞半径、皮肤余量和额外 7 厘米，寻路继续使用现有 A* 与线段碰撞检查。抵达后先停止移动和回正，转向果篮并等待至少 0.16 秒，再开始 Eat。

水果从果篮中部出发，送到嘴边时继续按当前骨骼网格的前表面保持间距。吃完才记为一次已完成互动。点草地、点靶子、摸头、施放水枪、回到起点或切换场景可打断；暂停会冻结行走与进食。辅助触控标记为 40 CSS 像素，支持鼠标和手机点击。

实现位于 `animation-test/src/main.js`、`animation-test/src/resource-preview.js`；界面标记在 `animation-test/resources.html` 与 `animation-test/src/anime-ui.css`。

`npm run test:basket` 通过 7 项完整流程检查，包含实际果篮网格点击、每步障碍检查、到达后才进食、重复点击、取消与原生手机触控。报告位于 `docs/garden-basket-tests.json`；另已通过移动、技能键回归和生产构建。
