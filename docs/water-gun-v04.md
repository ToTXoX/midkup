# 更饱满的卡通水枪 v0.4

日期：2026-11-03。

- 主体基础半径从 0.017 米改为 0.052 米，约为原来的三倍；嘴边采用单独的细水颈，沿前进方向逐渐展开，水头更宽。
- 速度从 5 提高到 9 米/秒，调整重力后每单位前进距离的下坠约减少 38%，先向前冲再落地。
- 水体采用低饱和的浅青灰与白色高光，减轻蓝色和厚重感。起喷口部水珠缩小，口部连接直径保持在 0.045 米以内，中前段保留饱满的体积。
- 落地水花整体放大至 1.55 倍；水滴、水纹和湿斑同步放大，保持原来的简洁轮廓与短暂消散节奏。
- 调整喷水预览的镜头，容纳完整水束、飞行水头和落点。

`npm run test:water` 新增水束直径和喷速检查，继续验证暂停、慢放、反向拖动、重复播放及手机构图。结果见 `water-gun-v04-tests.json`。

正常速度视频：`renders/cartoon-water-v04.webm`。源码仍为 `animation-test/src/water-gun-effect.js`，资源包中同步为 `game-assets/fx/water-gun.js`。
